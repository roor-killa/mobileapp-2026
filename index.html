Stripe · 03
Stripe Payment Sheet - Saisie de carte
Interface de paiement Stripe native (Payment Sheet SDK) en mode TEST. L'utilisateur peut payer par carte bancaire, Bancontact, Amazon Pay ou EPS. Les données de carte ne transitent jamais par le backend Laravel - elles sont envoyées directement à Stripe, garantissant la conformité PCI-DSS.

✅ Enregistrer sous 04_recharge_ok.png
Stripe · 04
Confirmation - Recharge réussie
Dialogue de confirmation après une recharge de 10,00 € réussie. Le backend a vérifié le statut du PaymentIntent Stripe (succeeded), crédité le solde de l'utilisateur, créé une entrée en base de données et enregistré un bloc dans la chaîne d'audit (SHA-256). Le nouveau solde est affiché instantanément.

📷 Enregistrer sous 06_qr_code.png
Flutter · 06
QR Code - Paiement 5,00 €
L'utilisateur génère un QR code pour recevoir 5,00 €. Le QR encode un token UUID unique avec une expiration de 30 secondes (visible dans le compteur). Une fois scanné par le payeur (qui entre son PIN), le token est marqué comme utilisé et ne peut plus être réutilisé. La transaction est ensuite enregistrée et tracée dans la chaîne d'audit.
TTL 30s · Usage unique
