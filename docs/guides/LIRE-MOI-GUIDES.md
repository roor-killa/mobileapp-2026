# Guides « pour débutant »

Ces fichiers expliquent **pas à pas** comment utiliser chaque partie du dépôt, sans supposer que tu connais déjà Flutter, Laravel ou Docker.

## Ordre de lecture conseillé

1. **[01-MyBank-Flutter-et-Laravel.md](01-MyBank-Flutter-et-Laravel.md)** — Application mobile MyBank avec vraie API.
2. **[02-SECONDAPP-Web-bancaire-et-facturation.md](02-SECONDAPP-Web-bancaire-et-facturation.md)** — Application web (navigateur) + facturation type Odoo.
3. **[03-SecondApp-Flutter-json-server.md](03-SecondApp-Flutter-json-server.md)** — Petite app Flutter qui lit les mêmes données mock qu’une API locale.

## Avant toute chose

- Installe **Git**, **Node.js**, et selon le guide : **Flutter**, **PHP**, **Composer**, **Docker Desktop**.
- Ouvre toujours un terminal dans le bon dossier (les commandes `cd` sont indiquées dans chaque guide).
