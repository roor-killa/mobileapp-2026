# 🧊 IceBank — Application Bancaire Mobile

> Application bancaire mobile complète avec cryptomonnaies et IA
> Développée par **Tevi Elolo Peniel Lawson Body** — L3 Informatique 2026

---

## 📱 Description

IceBank est une application bancaire mobile moderne intégrant :
- 🏦 Gestion de compte bancaire (solde, transactions, virements)
- 💳 Gestion de carte (paramètres, opposition, PIN)
- ₿ Cryptomonnaies en temps réel (BTC, ETH, SOL, AVAX, XRP, USDT)
- 🤖 Assistant IA bancaire intelligent (IceAI / OpenAI)
- ⚡ Paiements instantanés Wero

---

## 🛠️ Technologies

| Couche | Technologie |
|--------|-------------|
| Frontend | Flutter 3.x / Dart |
| Backend | Laravel 10 / PHP 8.2 |
| Base de données | MySQL 8.0 / SQLite |
| Authentification | Laravel Sanctum |
| Crypto API | CoinGecko API |
| IA | OpenAI GPT-3.5 |
| Infrastructure | Docker + Docker Compose |

---

## 🚀 Lancer le projet
```bash
# Backend
cd projet/backend
composer install
php artisan migrate --seed
php artisan serve

# Docker
cd infrastructure
docker-compose up -d
```
